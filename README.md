# Индекс риска работ повышенной опасности — прототип

Прототип к заявкам на ежегодный конкурс Председателя Правления АО НК «КазМунайГаз» «Лучшие инновационные идеи и практики в области охраны здоровья, труда и окружающей среды» (2026).

Две идеи, один контур данных:

1. **Индекс риска работ повышенной опасности** — ИИ-оценка наряда-допуска и бригады до начала работ на опережающих индикаторах систем, которые группа уже внедряет (ЭНД, TUMAR, «Управление поездками», «Қорғау», реестр инцидентов), плюс фотопроверка места работ телефоном и разбор актов расследования.
2. **Паспорт безопасности подрядчика в закупках** — рейтинг подрядчика по ПБ из тех же данных, который автоматически учитывается при допуске к работам повышенной опасности.

## Экраны

| Файл | Что показывает |
|---|---|
| `index.html` | Проблема в трёх цифрах и схема контура |
| `смена.html` | Экран мастера: наряды на смену со светофором, факторы, мероприятия |
| `карта.html` | Экран ДПБ: ДЗО, объекты, тренды, извлечённые уроки |
| `эффект.html` | Калькулятор денежного эффекта с формулой и источниками |
| `подрядчик.html` | Паспорт безопасности подрядчика и гейт в закупках |
| `дорожная_карта.html` | Тираж по ДЗО по кварталам |

Открывается любым браузером с диска или по адресу GitHub Pages. Без сборщиков и серверов.

## Ролик

`медиа/ролик.mp4` — 72 секунды, как работает светофор наряда. Сделан кодом: `ролик/ролик.html` — одна HTML-страница, где всё в кадре нарисовано HTML/CSS/SVG, а время — аргумент функции `renderAt(t)`; `ролик/музыка.py` синтезирует звуковую дорожку numpy и scipy; `ролик/рендер.py` снимает страницу покадрово в MP4 через Playwright и ffmpeg. Открыть в плеере: `ролик/ролик.html` с локального сервера (через `file://` шрифты не загрузятся). Концепция и раскадровка — `ролик/КОНЦЕПЦИЯ.md`.

## Данные

**Все данные на экранах — демонстрационные.** Они генерируются в `данные.js` детерминированно и не содержат реальных нарядов, бригад, людей, подрядчиков или нарушений. Публичные показатели группы на обложке взяты из годового отчёта КМГ за 2025 год с указанием источника.
