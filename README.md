# Индекс риска работ повышенной опасности — прототип

Прототип к заявкам на ежегодный конкурс Председателя Правления АО НК «КазМунайГаз» «Лучшие инновационные идеи и практики в области охраны здоровья, труда и окружающей среды» (2026).

Две идеи, один контур данных:

1. **Индекс риска работ повышенной опасности** — ИИ-оценка наряда-допуска и бригады до начала работ на опережающих индикаторах систем, которые группа уже внедряет (ЭНД, TUMAR, «Управление поездками», «Қорғау», реестр инцидентов), плюс фотопроверка места работ телефоном и разбор актов расследования.
2. **Паспорт безопасности подрядчика в закупках** — рейтинг подрядчика по ПБ из тех же данных, который автоматически учитывается при допуске к работам повышенной опасности.
