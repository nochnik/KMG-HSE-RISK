# Ролик «Светофор наряда» — концепция (09.10.2026)

Для заявки на конкурс Председателя Правления КМГ по ПБ, ОТ и ОС: «Индекс риска работ повышенной опасности». Ролик прикладывается к письму и показывается на защите. Длительность 60–70 с, 1920×1080, 30 к/с, без диктора, с синтезированной музыкой. Всё нарисовано кодом по шаблону `шаблон/ролик.html`.

## Идея одной фразой

Четыре системы видят нарушение, когда оно уже случилось. Индекс отвечает заранее — и мастер решает до начала работ. Сначала люди, потом тенге.

## Визуальный язык

Айдентика КМГ: светлая «бумага» `#F5F9FC`, белые окна с рамкой `#231F20`, синий КМГ `#02AEF0`, голубой `#90D6F7`, тёмно-серый текст `#231F20`. Светофор: зелёный `#1B8A4C`, янтарный `#D98E04`, красный `#C8102E`. Тёмный «мир» только для интро и сцены эффекта: `radial-gradient(#0b2a44, #04101c)`. Шрифты из `vendor/fonts` (Inter Tight 900 — заголовки и цифры, Jost 700/800 — подписи, JetBrains Mono — номера нарядов и значения). Логотип КМГ — `assets/лого_кмг.png` (скопирован из прототипа), только на финале и мелко в углу светлых сцен.

Экраны мастера и ДПБ перерисовываются из UI-кита по макетам прототипа `KMG-HSE-RISK` (кадры `кадры/02_смена.png`, `03_карта.png`, `04_эффект.png`): таблица нарядов, светофор, панель факторов, карточки ДЗО со sparkline. Не вставлять скриншоты картинкой — только кубики, чтобы всё анимировалось.

## Музыка

Копия `_образец/kmgd-showreel/showreel_music.py` → `музыка.py` с сеткой под этот монтаж: темп подобрать так, чтобы смены сцен попадали на сильную долю; интро тише, сцены 3–4 плотнее, сцена 7 — только пэд и колокол (без бочки: речь о людях), финал — светлый аккорд. Нормализация −14 LUFS. Длина = длительности ролика.

## Правила

- Всё обезличено: бригады «КРС-02», наряды «НД-3321», ДЗО — только коды. Фамилий, номеров техники, сумм договоров нет.
- Цифры в подписях — только из заявки (10,38; 1 из 3; 3; 1,8; ≈7; >20; +44 млн). Значения внутри макетов — иллюстрация.
- Никакого накопленного состояния: кадр — функция от t.
- Имена в коде — по-русски, как в шаблоне.
